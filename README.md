# PeriodicAlchemy20Mod (Fabric 1.20.1)

Великая Таблица Менделеева: Реакции и Стабилизация.

## Игра
- Реактор `chemtable:chem_reactor` — соберите до 4 элементов.
- ПКМ элементом по реактору добавляет элемент.
- ПКМ стабилизатором — включить режим запечатывания.
- Shift+ПКМ пустой рукой — запустить реакцию.
- Справочник `chemtable:chem_book` — 20 рецептов и памятка.

## Команды
- `/givechem` — реактор, книга, стабилизатор и все 12 элементов.

## Сборка
JDK 17, Gradle 8.8, workflow GitHub Actions прилагается.
